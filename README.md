<h1 align="left">Seja bem vindo ao Tela00s!</h1>

<p align="left">
Este projeto foi desenvolvido com o intuito de praticar o uso do Axios no Vue.js e a manipulação de dados.
</p>

---

<h2 align="left">📥 Tutorial de instalação</h2>

<h3 align="left">1. Abra, no terminal, a pasta onde deseja clonar o repositório e digite:</h3>

```bash
git clone https://github.com/LucasFontini1/Tela00s.git .
```

<h3 align="left">2. Após isso, abra o terminal na pasta raiz do projeto e execute:</h3>

```bash
npm install
```

<h3 align="left">3. Para rodar o projeto, utilize:</h3>

```bash
npm run dev
```

<h4 align="left">Pronto! O projeto estará rodando localmente.</h4>
